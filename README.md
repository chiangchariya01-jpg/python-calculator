# Python Calculator

A simple calculator built using Python.

## 🚀 Features:
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Power (**)
- Modulus (%)
- Loop for continuous use
- Error handling (division by zero)

## 💻 How to Run
1. Install Python
2. Run:
   python calculator.py

## 📸 Example
Enter first number: 21
Enter secong number: 15
Choose (+, -, *, /, **, %): *
Result: 100
